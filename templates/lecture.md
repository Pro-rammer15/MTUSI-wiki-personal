# Название понятия

## In one sentence

Git - система контроля версий
GitHub - сервис, в который мы постим свои Git позиторий

## Explanation

Git - нужен нам для контролся версий в VsCode ( там есть даже отдельная плашка)

GitHub - нужен нак для того, чтобы работать в команде и брать этот репризиторий из любой точки мира

## Example

команда git init - создает git хранилице
потом нужна команда git add . чтобы зафиксировать все
изменения в файле
после надо зафиксировать и создать коментарий командой git commit -m 'Тут пояснение'

## Boundaries and common mistaces

Git - система контроля версий, а вот Git - это то, где мы храним репрезитории (Они разные)
